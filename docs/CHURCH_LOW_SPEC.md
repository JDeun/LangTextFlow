# 교회·비영리 행사 저사양 실행 안내 (시험 운용)

LangTextFlow는 교회에서 GPU 서버나 유료 API 구독 없이도 사용할 수 있도록
**경량 CPU 모드**를 시험 중입니다. 이 안내는 원문 한국어 실시간 자막 기준입니다.
영어·일본어 통역이 완성되었다는 뜻이 아닙니다.

> 현재 **GPU 없는 4GB/8GB PC는 목표 시험 장비이며 지원 보증이 아닙니다.**
> 실제 서비스 전 예배 시간에 맞춘 장시간 현장 테스트가 필수입니다.

## 1. 처음 준비하기

1. Windows 또는 macOS에서 [개발자/소스 설치](../README.md#개발자--source-실행)에 따라
   Python 환경과 `faster-whisper` 의존성을 설치합니다.
2. 앱을 열고 **PC 사양에 맞게 선택 → 저사양 CPU 모드**를 선택하면
   환경변수 편집 없이도 해당 세션에서 CPU faster-whisper base/INT8를 사용할 수 있습니다.
3. 설치 장비에서 저사양을 항상 강제하려는 관리자만 저장소 최상위의
   `.env.example` 파일을 `.env`로 복사합니다.
4. 복사한 `.env` 파일 끝에 다음을 추가합니다.

```dotenv
LANGTEXTFLOW_RESOURCE_PROFILE=low
LANGTEXTFLOW_LOW_RESOURCE_WHISPER_MODEL=base
LANGTEXTFLOW_LOW_RESOURCE_CPU_THREADS=2
```

5. 앱을 실행한 후 초기 설정에서 **faster-whisper**가 준비되었는지 확인합니다.
6. 모델이 없다면 모델 준비 화면에서 `base` 모델 다운로드를 명시적으로 실행합니다.
   **행사 진행 중 다운로드가 시작되지 않게** 먼저 캐시를 확인하세요.

저사양 `auto` 엔진은 VibeVoice 7B를 시작하지 않고 CPU faster-whisper로
작동하도록 설계되어 있습니다. 화면의 엔진을 `VibeVoice`로 직접 지정하면
예외적으로 고사양 서버를 사용할 수 있으므로 피하세요.

## 2. CPU만 있는 컴퓨터에서 원문 자막 시작

1. 설교 언어를 `한국어`로 선택합니다.
2. **ASR**: `Auto`(저사양 환경 설정 시 CPU faster-whisper) 또는
   `faster-whisper`를 선택합니다.
3. **교정**: `규칙 기반 보정만`을 선택합니다.
4. **번역**: `번역 사용 안 함`을 선택합니다.
5. 오디오 입력은 가능하면 강당 내장 마이크보다 **교회 음향 믹서 AUX/라인 출력**을
   USB 오디오 인터페이스로 연결해 잡음을 줄입니다.
6. 실제 예배가 아닌 연습 시간에 10~30분 연속으로 테스트한 다음 운영합니다.

이 구성은 원문 자막만 표시합니다. 화면에서 영어를 선택했더라도
영어 번역이 생성되는 것은 **아닙니다**. 로컬 소형 번역 기능은
[GPU 없는 번역 품질 과제](https://github.com/JDeun/LangTextFlow/issues/106)
에서 별도로 검증합니다.

## 3. 너무 느리거나 음성이 누락되면

- `tiny`는 더욱 가볍지만 초기 한국어 FLEURS 3개 샘플 평가에서 오류율이
  높았습니다. 정확도 측정 없이 교회 예배용 기본값으로 변경하지 마세요.
- PC가 감당하지 못한다면 사용 중인 번역/교정 모델을 추가로 실행하지 말고,
  사용하지 않는 프로그램을 닫아 리소스를 확보하세요.
- 원문을 바탕으로 한 사후 요약도 **검수된 전사문**이 없으면 부정확할 수 있습니다.
- 강당에서 오류가 잦다면 먼저 입력 음원·볼륨·잔향을 확인하세요.

## 4. 공동체 사용을 위한 검증 조건

최소한 실제 사용하는 PC에서 CPU/RAM, 운영체제, 평균·p95 자막 지연,
음성 인식 CER/WER, 모델 캐시 크기, 최고 RAM, 오디오 누락 여부,
30/60/90분 연속 운영 및 전원 복구를 기록해야 합니다.
**CI의 통과 결과는 4GB 장비에서 실시간 통역이 된다는 증거가 아닙니다.**

최종 목표는 GPU가 없는 저렴한 PC 한 대에서 한국어 설교를 영어로
정확하고 지속적으로 전달하는 것이며, 이 목표의 달성은
[검증 이슈 #106](https://github.com/JDeun/LangTextFlow/issues/106),
[장비 검증 이슈 #107](https://github.com/JDeun/LangTextFlow/issues/107)로 추적합니다.
