# Immutable source records

This directory contains **source metadata and permitted excerpts**, not full copies of third-party articles, model weights, audio, or personal data. Use one new Markdown record per source revision. Once committed, do not overwrite: append a correction record linking the original. For existing canonical reports, link to them rather than duplicating their contents.

Record template: `Title`, `Source URL/permalink`, `Retrieved YYYY-MM-DD`, `Revision/hash`, `License/rights`, `Evidence class`, `Tracking issue`, `Summary and verification gaps`.

Follow [schema](../schema.md).
